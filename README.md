# 📚 Web Scraping - Books Dataset

## 🎯 Project Overview
Scraped 1000 books from [books.toscrape.com](https://books.toscrape.com) using Python & BeautifulSoup.

## 📊 Dataset Details
| Column | Description |
|--------|-------------|
| Title | Book name |
| Price (£) | Book price in GBP |
| Rating (1-5) | Star rating |
| Availability | In stock / Out of stock |
| URL | Book detail page link |

## 🛠️ Tools Used
- Python 3
- BeautifulSoup4
- Requests
- OpenPyXL

## 📈 Results
- ✅ 1000 Books collected
- ✅ 50 Pages scraped
- ✅ Data saved as Excel file
- ✅ Average Price: £35.07

## ▶️ How to Run
```bash
pip install requests beautifulsoup4 openpyxl
python WebScraping.py
```

## 📁 Files
- `WebScraping.py` - Main scraper script
- `CodeAlpha TASK-1.xlsx` - Final dataset
